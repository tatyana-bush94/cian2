# Движение, камера, типографика

Ориентир — ролики Linear, Notion, Figma Config, Stripe Sessions: чистая типографика, много воздуха, быстрые смены кадров, живые микро-анимации. Структура экранов — как в продукте, подача — «видео-вайрфрейм»: крупнее, проще, без второстепенных элементов. Цвета и шрифт — из бренд-профиля (`brand.md`).

## Цвет
- **Один акцент** (`--accent`) — только там, где пользователь действует или говорит: главная кнопка (CTA), реплики пользователя в чате, ссылка оценки, его звёзды, блик анимации обработки. Если акцентных точек в кадре больше одной-двух, глаз перестаёт понимать, куда смотреть.
- **Всё «включённое»** (выбранный чип, сохранённое, активный фильтр, метки под вводом, тосты) — графит `--dark`, а не акцент.
- **Перелив** (`E.grad`, цвета `--ring-stops`) — только на обводке поля ввода и поля на финальной карточке; угол растёт со временем (`t*55`), свечение — тот же градиент с размытием 34 px и прозрачностью .30. Нет поля ввода в продукте — перелив не нужен.
- Ошибка, предупреждение — только в сценах про сбой, своим цветом продукта, не акцентом.
- Нельзя: неоновые и радужные градиенты вне поля, 3D-роботы, «мозги из нейросетей», бинарный код, голограммы, стоковые люди и рукопожатия. Тёмным бывает экран обработки (затемнение поверх интерфейса) или весь интерфейс, если продукт тёмный.

## Типографика
Шрифт продукта из `brand/fonts`; веса — только существующие (`--w-regular`, `--w-medium`, `--w-bold`). Крупное — жирным с отрицательным трекингом.

| Элемент | Размер / вес / трекинг |
|---|---|
| Белый экран-заставка | 104 (v) – 112 (h) / bold / −0.03em, слова выезжают снизу |
| H1 стартового экрана | 56 / bold / −0.03em |
| Подзаголовок | 21 / regular, `--ink2` |
| Текст в поле ввода | 24 / regular, в одну строку |
| Метки под фрагментами ввода | 13.5 / medium, белые на графите |
| Название раздела в шапке | 18 / bold |
| Заголовок выдачи | 30 / bold / −0.025em |
| Интерфейс (кнопки, чипы, чат) | 14.5–17 / medium |
| Название карточки | 19 / bold / −0.02em |
| Фразы экрана обработки | 26 / bold, белые |
| Субтитры | 31/42 (h) · 42/54 (v) / medium |
| Финальная карточка | 86 (h) · 70 (v) / bold; подпись 32 · 34 |

Размеры — в логических пикселях полотна (`PLAN.canvas`, по умолчанию 1600×960); камера увеличивает их в 1–2.4 раза, поэтому мелкий UI-текст на экране читается.

## Движение
| Что | Как |
|---|---|
| Появление элемента | `eout`, 0.3–0.45 с, подъём на 16 px, прозрачность 0→1 |
| Каскад (карточки, строки) | шаг 0.1 с, карточка падает на 28 px и растёт 0.985→1 |
| Исчезновение / перестроение | `eio`, 0.25–0.35 с; перестраиваемые едут в новые слоты, удалённая сжимается до 0.94 и гаснет |
| Печать текста | 18–24 символа/с, каретка; в покое мигает 2.4 Гц |
| Метка под фрагментом | `eout` 0.3 с: прозрачность, сдвиг −6 px, масштаб 0.9→1; гаснут вместе к следующей фразе |
| Клик | курсор «вжимается» на 16 %, рябь 0.55 с, кнопка проседает до 0.95 |
| Счётчики | тикают 1–1.5 с с `eout`, цифры табличные |
| «Думает» | три точки, синус по фазам; на экране обработки — сменяющиеся фразы этапов |
| Тёмный экран | затемнение 0.35 с вверх; результат подменяет стартовый экран **под** затемнением, затем затемнение уходит за 0.35 с и элементы выдачи въезжают каскадом |
| Модалка | 0.3 с, подъём 14 px и масштаб 0.96→1; камера начинает наезд в момент клика, модалка проявляется на его середине |

Темп: смена плана каждые 2–4 с (панорама, зум, новый экран). Между ключевыми точками камеры — пары кадров с лёгким дрейфом (+4 px, +0.03 масштаба): кадр «живёт», а не замирает.

## Камера
Ключи `[t, x, y, масштаб]` в координатах полотна (центр — `[CW/2, CH/2]`), интерполяция `eio`, масштаб — в логарифмической шкале. Точки — из замеров (`E.rect`), не на глаз.

| План | 16:9 | 9:16 |
|---|---|---|
| Общий (весь экран) | 0.98–1.02 | 0.6–0.66 (весь), 1.15 (центральная колонка) |
| Средний (поле, панель) | 1.2–1.35 | 1.25–1.45 |
| Текст ввода крупно | 1.5–1.55 | `min(1.75, 980 / ширина текста)` — во всю ширину кадра |
| Крупный (кнопка, поповер, сообщение) | 1.6–1.8 | 1.9–2.4 |
| Модалка | 1.7 | 2.0 |

Значения — для полотна 1600×960; при другом `canvas` пересчитай общий план так, чтобы окно занимало 60–100 % ширины кадра.

Якорь — точка кадра, куда камера ставит цель: центр кадра в 16:9, `(540, 1000)` в 9:16 (чуть ниже центра — кадр не уходит под субтитры). У нижнего края полотна держи `y ≤ CH − (H − якорь_y) / масштаб`, иначе под полотном видна пустая полоса.

## Вертикаль 9:16
Те же сцены и тот же DOM, свои ключи камеры: интерфейс крупнее, текст ввода — во всю ширину, панели — 1.42, в выдаче — центральная колонка, боковые панели — отдельными наездами. Субтитры — на 330 px от низа, выше нижней панели мессенджеров; в две строки — нормально.
