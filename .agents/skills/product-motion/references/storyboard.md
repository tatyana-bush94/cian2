# Сценарий: от «видео на X секунд о фиче» до таблицы

Факты о фиче и бриф — `brief.md`. Здесь — как из них сложить ролик.

## Скелет по длительности
| Длительность | Сцены | Реплик |
|---|---|---|
| 15 с | хук 2–3 с → одно главное действие 8–9 с → финал 3–4 с | 2–3 |
| 30–35 с | хук 3–4 → главное действие 6–7 → подсказка или второй способ 2–3 → обработка 4–5 → результат с объяснением 6–7 → следующее действие 2–3 → финал 3–4 | 8–11 коротких |
| 45 с | + уточнение / второй сценарий 8–10 с | 10–12 |
| 60–75 с | хук · 2–3 сценария фичи · обработка · результат · объяснение · уточнение · управление результатом · обратная связь · финал | 14–16 |

## Архетипы фичи → какой сюжет
| Фича | Сюжет | Рецепты (`scenes.md`) |
|---|---|---|
| Поиск, подбор, генерация по запросу | ввод → обработка → результат → «почему» → уточнение | печать с метками, тёмная обработка, каскад, поповер, чат |
| Процесс, заявка, пайплайн | объект → этапы → сбой/ожидание → действие → продолжение | статусы этапов, ошибка → восстановление, таймлайн |
| Дашборд, аналитика | вопрос → фильтр → график меняется → вывод | выпадашки фильтров, счётчики, перестроение |
| Настройка, интеграция | было неудобно → включили → стало | переключатели, тост, до/после |
| Совместная работа | действие одного → реакция другого | два курсора, уведомление, комментарий |
| Онбординг | 3–4 шага по порядку | шаги с прогрессом, подсветка элемента |

## Опорные моменты
- **Хук** — боль аудитории без продукта (бесконечный список, десятки фильтров, хаос таблиц) и резкий стоп. Одна короткая фраза на белом экране. Музыка обрывается вместе со стоп-кадром. Для инвесторского или промо-ролика хук может быть проблемой рынка; для обучающего — можно начать сразу с интерфейса.
- **Главное действие** — курсор и печать: человек видит, что делать, словами из интерфейса.
- **Свободный ввод** — показать, как формулировать: под фрагментами ввода встают метки ровно на словах голоса; при двух способах формулировки — «выделить всё» и перепечатка вторым способом.
- **Обработка** — что именно делает система (выделяет критерии, сверяет, проверяет), а не «магия». Фразы этапов — из продукта.
- **Результат** — каскад, счётчик, и сразу объяснение («почему подходит», причина ошибки, источник цифры) — это доверие.
- **Финал** — название фичи · продукт, короткое приглашение. Последняя реплика — приглашение, не лозунг. Последние `hold` секунд — без речи.

## Голос и плотность текста
- Темп речи ≈ 2.5–2.8 слова/с; голосом занято 60–70 % ролика, остальное — паузы, где говорит интерфейс. Итого **1.3–1.6 слова на секунду ролика** (72 с ≈ 105 слов).
- Реплика — 1–2 коротких предложения, глаголы в повелительном или настоящем времени: «Опишите, что ищете», «Подборку можно уточнять как в переписке».
- Каждая реплика называет то, что сейчас на экране. Ключевое слово реплики = момент события (`E.sync('p3:слово', …)`).
- Перечисление в голосе = метки на экране, в том же порядке.
- Тон: уверенный, тёплый, без корпоративного пафоса и без «революционного ИИ».
- Субтитры: строка ≤ 56 символов; длиннее — `align_vo.py` делит по знаку препинания ближе к середине (или задайте `vo[].subs`).

## Титров нет (по умолчанию)
Плашки-титры дублируют голос и закрывают интерфейс. Текст на экране — субтитры; ролик сдаётся в двух версиях: с субтитрами и без (`--qs subs=0`). Крупный текст — только на белом экране хука и на финальной карточке. Если пользователь хочет титры — движок умеет (`PLAN.titles`).
