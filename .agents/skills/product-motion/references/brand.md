# Бренд-профиль проекта

Один профиль на продукт: `<проект>/motion/brand/` (или рядом с другими видео проекта). Каждый ролик получает его копию в `<ролик>/brand/` при `new_project.py --brand …` — так старые ролики пересобираются одинаково, даже если профиль потом изменится.

```
motion/brand/
  brand.css      токены и @font-face
  fonts/         локальные файлы шрифтов (+ лицензия)
  logos/         знак и логотип продукта (SVG)
  README.md      откуда взяты значения, права на шрифты и логотипы, дата
```
Начни с копии `templates/brand/` скилла и замени значения.

## Откуда брать значения
| Токен в `brand.css` | Где искать в проекте |
|---|---|
| `--accent`, `--accent-ink` | основной цвет кнопок: CSS-переменные (`--primary`, `--brand`), тема (`theme.ts`, MUI/Chakra theme), `tailwind.config` (`colors.primary`), дизайн-токены (`tokens.json`) |
| `--ink`, `--ink2`, `--ink3` | цвета текста: foreground / muted / subtle |
| `--line`, `--line2`, `--soft`, `--surface`, `--bg` | границы, подложки, фон карточек и страницы |
| `--dark` | «включённые» состояния, тосты, тёмные метки — обычно самый тёмный нейтральный |
| `--dim` | цвет затемнения (тёмный экран обработки, подложка модалок), r,g,b |
| `--ring-stops` | градиент поля ввода, если он есть в продукте; иначе 2–3 оттенка акцента |
| `--font`, `--w-*` | шрифт продукта и веса, для которых есть файлы |
| `--r-app` | радиус окна приложения |

Нужен и тёмный интерфейс? Меняйте `--surface`, `--ink*`, `--line*` на значения тёмной темы продукта и проверьте контраст субтитров (`--sub-bg`).

Компоненты, специфичные для продукта (своя шапка, свои карточки, свои кнопки), — в `brand.css` ниже токенов или в `<style>` ролика. `base.css` не правьте под продукт: это общий набор.

## Шрифты
- Только локальные файлы в `brand/fonts/`: во время рендера сеть не используется, CDN и Google Fonts не подгружаются.
- Проверь права: открытые (OFL и т.п.) — приложи лицензию; коммерческие — спроси пользователя, есть ли лицензия на видео. Без ясности — нейтральный Manrope (OFL) из профиля скилла и вопрос пользователю.
- Кириллица: если шрифт продукта без неё, подбери пару с кириллицей и зафиксируй это в README профиля.
- Веса: используй только существующие файлы или диапазон вариативного шрифта; `verify_scene.py` проверит, что шрифт загрузился.

## Логотипы
- Только логотипы продукта пользователя, из его репозитория или от него самого. Не перекрашивай и не рисуй самодельные знаки за реальные.
- `logos/mark.svg` — знак для шапки и финала; при наличии — `logos/wordmark.svg`.
- Чужие бренды (партнёры, клиенты) — только если пользователь прямо дал их и разрешил.

## Кадр-образец
Перед первым роликом на новом профиле: собери демо из шаблона с этим профилем и покажи 2–3 кадра (стартовый экран, выдача, финал). Пользователь подтверждает акцент, шрифт и общий вид — после этого профиль используется без повторных вопросов.

## Чего не делать
- Не переносить акцент, шрифт и знаки одного продукта в другой.
- Не смешивать в кадре больше одного акцентного цвета.
- Не править профиль внутри папки ролика, если правка нужна всем роликам: правь `motion/brand/` и пересоздай копию.
