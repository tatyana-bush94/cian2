# Рецепты сцен

Каждый рецепт — интервалы времени и прогресс элементов в `scene(t)`. Готовая реализация первых девяти — в `templates/starter.html`; остальные собираются из тех же функций движка (`engine.md`). Подписи и данные — из продукта (`brief.md`), цвета — из бренд-профиля.

## Из демо-шаблона
1. **Хук «бесконечный список».** Сетка серых карточек со скроллом `y = 80t + 300t²`, размытие растёт со скоростью, резкий стоп-кадр, белый экран с одной фразой (слова выезжают снизу по очереди). Музыка обрывается на стоп-кадре.
2. **Появление экрана.** Элементы по очереди: `eout`, 0.45 с, подъём на 16 px, шаг 0.1 с.
3. **Печать с метками.** `E.markup(text, n, segs)`: фрагменты подсвечиваются, под каждым — метка `.mk-chip`, время метки = `max(конец печати + .2, E.sync('p3:слово'))`; гаснут вместе к следующей фразе.
4. **Перепечатка другим способом.** `markup(..., sel=true)` — «выделить всё» на 0.3–0.4 с, затем печать нового текста с нуля.
5. **Подсказка под полем.** Наведение курсора → подложка пилюли → панель раскрывается из пилюли (`env`), строки панели каскадом.
6. **Тёмный экран обработки.** Клик по CTA (кнопка проседает до 0.95) → `E.dim(.86)` за 0.35 с → `.proc` в `#app2`: `processing.js`, фразы этапов сменяют друг друга, чипы выявленных критериев, счётчик секунд. Смена экрана — под затемнением.
7. **Результат каскадом.** Боковые панели выезжают с краёв, карточки падают на 28 px с шагом 0.1 с, счётчик тикает 1–1.5 с с `eout` и склонением.
8. **«Почему подходит».** Клик по ℹ → поповер из точки клика (`transform-origin`), строки с галочками по очереди; камера крупно между значком и поповером.
9. **Действие + тост.** Кнопка меняет состояние (`el._on`), тост у верхнего края области (при зуме низ обрезается).
10. **Оценка.** Приглашение над полем чата → модалка в `#app2` поверх `E.dim(.45)` → звёзды по очереди → «Спасибо» с галочкой. Камера начинает наезд в момент клика, модалка проявляется на середине наезда.
11. **Финальная карточка.** Интерфейс гаснет, белая карточка: знак, «Фича · Продукт», подпись-призыв, поле с переливом и мигающей кареткой.

## Собрать из функций движка
12. **Чат: уточнение.** Печать в поле чата → сообщение пользователя (акцент) → «думает» (три точки, `sin` по фазам) → ответ. Высоты сообщений — замер в `setup`, рост — плавный (`height = MH × p`), лента прокручивается вверх.
13. **Перестроение списка.** Карточки притухают (0.6), удалённая сжимается до 0.94 и гаснет, остальные едут в новые слоты (`eio`, 0.3 с), счётчик 10 → 9.
14. **Выпадашка фильтра.** Клик по фильтру → `.pop.dd` из точки клика, выбранный пункт, фильтр получает графитовую подложку (`.fc .fon`), выдача перестраивается (13).
15. **Статусы этапов процесса.** Вертикальный список этапов, у каждого статус-пилюля; статус меняется на слове голоса: «В очереди» → «Проверка…» (точки) → «Готово» (галочка, `bump` масштаба). Прогресс-линия между этапами заполняется `lin`.
16. **Ошибка → восстановление.** Этап получает статус ошибки (единственный тревожный цвет в кадре, не акцент), раскрывается причина (поповер или строка), курсор жмёт «Повторить», статус проходит «Проверка…» → «Готово», дальше процесс продолжается.
17. **График меняется.** Столбцы или линия интерполируются между двумя наборами данных (`eio`, 0.5–0.7 с), подписи осей неподвижны, ключевое значение — счётчиком.
18. **Переключатель / настройка.** Клик → бегунок едет (`eio`, 0.2 с), подпись состояния меняется, рядом тост «Сохранено».
19. **Два участника.** Второй курсор (своё имя-бейдж, второй цвет — нейтральный, не акцент) делает действие; первому приходит уведомление. Второй курсор — отдельный элемент в `#app2`, его путь задаётся в сцене так же, как `E.cursor`.
20. **До / после.** Один и тот же экран дважды: «до» серее и плотнее, «после» — чище; переход — вытеснение по горизонтали или затемнение.
21. **Шаги онбординга.** Прогресс «1 из 4», подсветка элемента (затемнение вокруг через `E.dim` + вырез — элемент копией в `#app2`), подпись шага.

## Правила, общие для всех
- Событие на экране — на слово голоса, которое его называет.
- Перед камерой и позиционированием поповеров — замер (`E.measureAt` + `E.rect`).
- Всё, что над затемнением, — в `#app2`.
- Акцент — только там, где действует пользователь; «включённое» — графит `--dark`.
- Смена плана каждые 2–4 с; между ключами камеры — лёгкий дрейф, кадр не замирает.
