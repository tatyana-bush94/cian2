# product-motion

Скилл для Claude Code и Codex: короткие ролики о фичах продукта в стиле Linear и Stripe. В кадре — интерфейс продукта: курсор нажимает, текст печатается, метки встают под фрагментами ввода, камера ведёт взгляд, субтитры называют происходящее.

Подходит для обучающих роликов, промо, презентаций для инвесторов и лендинга. Демо и подробное описание — на [design.pvldchkv.ru/skills/product-motion/](https://design.pvldchkv.ru/skills/product-motion/).

## Как работает

1. **Бриф.** Фича, длительность, аудитория, язык, форматы. Чего не сказали — разумные умолчания, названные в ответе.
2. **Факты из проекта.** Агент читает код, прототип и `docs/` текущего проекта: экраны, точные надписи, состояния. Несуществующих функций в ролике нет.
3. **Бренд-профиль.** Один раз на проект: токены, шрифты и логотипы из кода собираются в `motion/brand/`. Без профиля — нейтральный профиль скилла для черновика.
4. **Сценарий.** Таблица «таймкод · что в кадре · камера · реплика».
5. **Сцены.** HTML-страница, где кадр — функция времени `render(t)`. Никаких CSS-анимаций, таймеров и записи экрана.
6. **Проверка кадрами.** `verify_scene.py` и контактные листы ключевых моментов — до полного рендера.
7. **Озвучка.** Скилл не синтезирует голос сам: готовит текст и промт для Gemini TTS, а присланную запись раскладывает по словам (`align_vo.py`).
8. **Музыка.** Черновой синтез по плану ролика или трек пользователя на таймлайне.
9. **Сборка и проверка.** Покадровый рендер Playwright + ffmpeg, сведение, проверка файлов (`verify_media.py`), по просьбе — материалы для сайта (`export_web.py`).

## Что на выходе

- MP4 16:9 и 9:16, с субтитрами и без; SRT.
- Пакет для озвучки: текст, промт для Gemini TTS, таблица таймингов.
- Контактные листы кадров.
- Для сайта: чистый MP4, WebVTT, постер, финальный кадр.

## Требования

- Python 3.9+, ffmpeg и ffprobe.
- `pip install playwright numpy scipy pillow` и `python -m playwright install chromium`.
- Для раскладки озвучки — `faster-whisper`.
- Для ускоренной версии (`retime.py`) — ffmpeg с rubberband.

Проверка окружения: `python3 scripts/check_env.py`. Зависимости удобнее ставить в venv проекта.

## Установка

Скопируйте папку `product-motion` целиком: одного `SKILL.md` недостаточно, скилл использует `scripts/`, `templates/` и `references/`.

```bash
git clone https://github.com/dyachkovp/agent-skills.git
mkdir -p ~/.claude/skills && cp -R agent-skills/product-motion ~/.claude/skills/   # Claude Code
mkdir -p ~/.agents/skills && cp -R agent-skills/product-motion ~/.agents/skills/   # Codex
```

Перезапустите агента и попросите, например: «сделай ролик на 30 секунд про экран поиска».
