# Источник: product-motion

Опубликованный снимок скилла. Исходники автор ведёт в приватном репозитории личных правил для агентов; сюда они попадают скриптом `scripts/sync.py` (см. `docs/updating.md` в корне каталога).

## Происхождение

- Скилл собран 2026-11-11 из собственного раннего скилла автора для роликов о фичах и из доработок, найденных при его применении в нескольких продуктовых проектах. Из проектов перенесены только обобщённые решения; их код, тексты и данные в скилл не входят.
- Брендовые ресурсы раннего скилла (шрифты, логотипы, цвета, тексты) удалены. Демо-ролик шаблона переведён в вымышленный продукт Demo.

## Отличия публичной копии от исходника

- Нет внутреннего файла происхождения — вместо него этот файл.
- Из `references/scenes.md` убран раздел со ссылкой на приватный образец.
- В комментарии `scripts/align_vo.py` заменён пример названия.

Точный список правок — в `catalog.json` корня каталога.
