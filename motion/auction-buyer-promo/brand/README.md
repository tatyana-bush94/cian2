# Циан · оформление роликов

Синий `#0054fd` — `--brand-blue` из `src/styles/global.css`.
Фон, основной текст и линии — из `SellerAuctionPage.module.css` и экранов прототипа.
Логотип — `public/images/cian-logo.svg`, без изменений.

Интерфейс в ролике используется как снимки настоящего прототипа: исходный шрифт
и оформление внутри снимков сохранены. Файлы Grtsk Peta в профиль ролика
не копируются. Для заголовков вне снимков используется Manrope, SIL OFL 1.1;
лицензия находится в `fonts/Manrope-OFL.txt`.

Дата: 23 ноября 2026. Исходники прототипа: коммит `8194e26`.
