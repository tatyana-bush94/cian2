# cian2 · Стек и UI-kit Циана

Приватный учебный репозиторий для практики «Три репозитория».

```sh
# Node.js 24; при наличии nvm: nvm use
npm ci
npm run dev
```

Прототип аукциона: `/`. Каталог компонентов: `/ui-kit`. Исходный справочник: `/reference/`.

На `/` и `/auction` прототип открыт в интерактивном мокапе iPhone: мобильная ширина,
Dynamic Island, строка состояния и прокрутка внутри экрана. Рамка подстраивается под
окно просмотра. Версия без рамки доступна по ссылке «Открыть без рамки» на `/auction/app`.

## Аукцион: сценарий продавца

Доступен мобильный учебный сценарий продавца: условия → проверка → публикация.
Выбранная квартира уже заполнена. Укажите стартовую цену целыми рублями, выберите шаг
25 000 / 50 000 / 100 000 ₽ и длительность 1 / 3 / 7 дней. На проверке можно вернуться
к редактированию без потери данных. Перед публикацией требуется подтвердить условия.

Публикация имитируется локально, ожидание длится 1,2 секунды. Для проверки ошибки
раскройте «Режим практики» и включите ошибку следующей публикации. Повторная попытка
сохраняет условия. После успеха доступен просмотр объявления без покупательских ставок.
Срок отсчитывается от успешной публикации, даты показаны по времени Новосибирска (UTC+7).

Черновик и результат сохраняются в браузере. Перезагрузка во время отправки возвращает
к проверке, не создавая ложного подтверждения. «Начать заново» создаёт новый учебный
черновик после подтверждения. Сервер, реальная публикация, оплата и юридическое оформление
не подключены. Сценарий покупателя подключён на `/auction/buyer`. Фотографии учебной квартиры — Unsplash.

Задачи практики — [tasks/](tasks/README.md), участники — [team/](team/README.md): у каждого свой файл `team/<github-логин>.md`. Свою работу ведите в ветке `<github-логин>/<задача>`.

React + TypeScript + CSS Modules + Vite. Всё необходимое для демонстрации работает локально. Зависимости закреплены, шрифты и UI-материалы хранятся в репозитории.

[Устройство, команды и API компонентов](docs/README.md).

Перед коммитом: `npm run typecheck && npm run lint && npm test && npm run build`.

Исходный UI-kit извлечён из публичного сайта Циана 12.11.2026. Это учебная адаптация, не официальный полный npm-пакет. Происхождение и ограничения перечислены в документации.

[Результаты проверки и скриншоты](docs/qa/README.md).

## Карта сценариев и аналитика

`/map` — отдельная страница с 30 миниатюрами реальных компонентов, основными и
альтернативными переходами, названиями целей Метрики и восемью метриками пилота.
Карту можно масштабировать, фильтровать по роли и выбирать экран для просмотра
его входов и выходов. Полный реестр переходов доступен в таблице с поиском.

Сценарий продавца: `/auction/app`, покупателя: `/auction/buyer`. Покупатель получает
условия последней публикации продавца из localStorage; без публикации открывается
учебный пример. Кнопки смены роли есть в обоих сценариях. В режиме практики
можно проверить ошибки, чужую ставку, завершение и сброс.

Цели отправляются через `src/analytics/auction.ts`: `METRIKA_COUNTER_ID = 0` —
заглушка, официальный тег не загружается, сетевых запросов Метрики нет. Проверка:
`window.__auctionGoals` (последние 200 событий в текущем окне) или журнал на карте
после перехода из сценария. События также доступны через `auction:goal` CustomEvent.

Каждая цель содержит `role`, `step`, `screen`, `session_id`, `flow_id`, `event_id`,
`timestamp_ms`, `prototype: true`. Отправки и ответы связаны по `attempt_id`, обе
роли — по `auction_id`. Повторная отправка создаёт новую попытку. События успеха
возникают только после ответа; повторное открытие сохранённого результата
конверсию не увеличивает. Снимки `/map/preview/:screen` изолированы от хранилища,
таймеров и аналитики, а их модальные окна не перехватывают фокус основной страницы.

Условные цели, формулы, знаменатели, окно пилота и правила принятия решения
описаны на `/map#metrics`. Для настоящего подключения требуется заменить ID,
инициализировать официальный тег и создать JavaScript-цели из реестра; демоданные
`prototype=true` нужно исключать из реального пилота.
